Releases tab on the right, or use this address, which always points at the newest one:

- Installer: https://github.com/cfunkycreations-tech/lyricist-releases/releases/latest/download/Lyricist-Setup.exe

## Windows will warn you the first time

Windows may show a blue "Windows protected your PC" box. Click **More info**, then
**Run anyway**. Every release lists a SHA-256 you can check.

On a Mac or a phone, use the web version: https://lyricist-pro.pages.dev
(Mac: open it in Safari, then File → Add to Dock.)
